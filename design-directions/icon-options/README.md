# Model app name and icon options

Open [index.html](./index.html) in a browser to compare the icon directions at app mark, sidebar, and favicon sizes.

The options use the current app language: a light surface, ultramarine `#3d4fd1`, rounded corners, and simple white outline geometry. Each SVG is a standalone asset that can later be copied to `src/app/icon.svg` or used in the app shell.

## Pairings

1. **Model Atlas** — ranked marker; the clearest overall fit for evaluations, rankings, and model selection.
2. **Model Atlas** — compass; the most direct visual match for the Atlas name.
3. **Model Index** — dot grid; precise and research oriented.
4. **Eval Atlas** — evaluation stack; emphasizes benchmark reports.
5. **Model Signals** — signal path; more brandable and performance focused.
6. **Model Atlas** — A monogram; simplest fallback for very small sizes.
