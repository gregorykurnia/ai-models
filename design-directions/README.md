# Leaderboard design directions

This folder contains a browser-ready visual comparison board for the Artificial Analysis leaderboard product described in [LEADERBOARD_PRODUCT_PLAN.md](../LEADERBOARD_PRODUCT_PLAN.md).

Open [index.html](./index.html) in a browser and switch between the four concepts:

1. **Editorial index** — a warm, source-led research surface. Strongest for trust, context, and a public-facing launch.
2. **Precision lab** — a bright instrument panel. Strongest for developers and repeat users who value scan speed.
3. **Utility grid — preferred** — a bright, modern, sleek comparison workbench. Strongest for practical model selection and visible filtering.
4. **Signal atlas** — an expressive, category-aware catalog. Strongest for discovery and giving the product a memorable point of view.

## Selected direction

The preferred direction is **Utility grid**. Keep the visual language bright, modern, and sleek, with clear comparison controls and the leaderboard easy to scan.

The sample rows use illustrative model names and scores so the layouts can be judged visually. The structural details come from the product plan: 15 standard evaluations, 4,948 parsed rows, provider filtering, source-rank preservation, metric labels, and bounded cost labels such as less than 0.1 cent.

The controls in the preview are intentionally lightweight: direction switching, model search, provider filters where shown, and local reset behavior. They are there to make the information architecture easier to evaluate, not to represent the final implementation.
