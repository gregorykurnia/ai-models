# Logo background explorations

This set keeps the Contour mark fixed and changes only the surrounding field. The solid ultramarine tile is included as the reference point.

My preference is to make the solid blue tile an accent use, then use one of these as the main identity treatment:

1. **Paper and ink** for a research-led, editorial feel.
2. **Lavender field** for the closest match to the existing UI palette.
3. **Topographic field** for the strongest Model Atlas story.
4. **Offset window** for a more ownable, layered mark.
5. **Midnight edge** for a compact favicon or dark-mode brand surface.
6. **Soft gradient** for marketing or launch surfaces where the identity can be more expressive.
7. **Transparent ink** when the logo should live directly beside the wordmark without a container.
