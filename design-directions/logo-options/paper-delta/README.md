# Paper and Delta logo preview

This is a visual proposal only. It combines the Paper and Ink background with the Delta mark before any app branding is changed.

The color system is intentionally restrained:

- Warm paper: `#f4f3ef`
- Dark ink: `#191a24`
- Existing ultramarine: `#3d4fd1`
- Existing border: `#dddde5`

The primary version uses dark ink for the outer Delta, ultramarine for the inner Delta and point, and the warm paper field for the tile. The same mark is shown without a tile for the sidebar lockup and in inverse colors for dark surfaces.

Open [index.html](./index.html) to view the visual preview.
