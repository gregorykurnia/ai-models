## Version and missing-result notes

- The 2026-09-29 workbook cohort is within Artificial Analysis Intelligence Index v4.3.2, whose official version history lists September 2026 through current. The current Haiku profiles report the same v4.3.2 suite and the same ten component evaluations; no version conflict was found.
- AA-Briefcase entries are separated into combined Elo, rubric percentage, analytical-quality Elo, and presentation Elo. The combined, analytical-quality, and presentation Elo values retain their published absolute 95% confidence intervals.
- MMMU-Pro is the only unresolved evaluation. All five model profile payloads return `mmmuPro: null`; the official MMMU-Pro page was checked, but its server-rendered payload exposed no score for these variants. No rows were added for it.
- 90 rows were added across the 18 evaluations with scores (18 per configuration). Each evaluation row count increases by five except MMMU-Pro, and each new row keeps the existing published snapshot ID. The master leaderboard therefore gains exactly five model identities.
- The five Intelligence Index task costs are the official profile values in the first table. Per-evaluation costs are included in coverage cells only where the profile payload publishes a task cost; token prices were not used as task costs.
- Runtime configuration is `DATA_SOURCE=firestore`. The data loader uses bundled entries when a published evaluation snapshot matches the bundled snapshot ID, and it reapplies profile overlays to remote entries when IDs differ. The implementation changes the bundled overlay and preserves snapshot IDs; no direct Firestore write was made.
