# Task suitability data audit

Audited the imported published workbook snapshot dated 29 Sep 2026 using `npm run audit:suitability` on 30 Sep 2026. The script verifies evaluation row counts, that every row uses its evaluation's published snapshot ID, rank bounds, exact model ID consistency, and the absence of duplicate model IDs within each evaluation. It runs the scorer across the full catalog and a three-evaluation example.

The snapshot has 16 evaluations, 5,618 ranked rows, and 850 original model IDs. All evaluations use the same capture date. No original ID maps to multiple provider/model labels, and no evaluation contains duplicate exact model IDs. All 5,618 rows have a usable rank. The planner matches 35 known sheet-label alias pairs using the master leaderboard's rules, producing 815 selectable variants. The full 815-variant, 16-evaluation calculation completed in about 0.51 seconds in the recorded audit run.

For example, “Claude Opus 5.5 (Adaptive Reasoning, Max Effort, Default Fallback)” and “Claude Opus 5.5 (max with fallback)” share coverage. Max and Xhigh, or fallback and no fallback, remain separate. A variant is identified by a deterministic representative existing model ID, with its equivalent source IDs pinned alongside the saved input rows. No source IDs or imported snapshots were rewritten. Earlier saved tasks lacking alias metadata retain their original exact-ID results.

Intelligence Index has 670 rows: 179 independently scored and 491 estimates. It has 68 `Unknown` provider rows. This follows the importer policy: providers are assigned only from exact, unambiguous matches in the other sheets. The scorer keeps every Intelligence Index rank, including estimates; it does not interpret the scoring status as a score adjustment.

Coverage varies: 90 variants are present in all 16 evaluations, while 132 appear in only one. As a concrete partial-data review, the audit selects Briefcase v1.1, Finance & Accounting, and Intelligence Index at equal weights. Of 815 candidates, 150 have complete coverage and 665 are partial; 1,392 selected evaluation cells remain “Not ranked.” Claude Opus 5.5 (max with fallback) leads the complete-coverage set at 100 with weighted average rank 1. These figures verify the missing-data behavior against source rows, rather than recommend evaluations for a particular user's task.

The browser displays each selected evaluation's capture date in its picker, preflight summary, and score breakdown. Methodology is linked from the [data notes](../src/app/about/data/page.tsx) and the planner itself. Result links use the original model label from each matched source row, so a different sheet-label format still opens a matching result. Estimated or independently scored status remains visible in the table and breakdown. The source data does not provide an external source URL for Intelligence Index.

Product event names follow the rollout plan. This app has no central analytics service configured, so their aggregate counts stay in a separate browser storage key on the user's device. Only eight event-name counters are stored; no task text, selected evaluation IDs, model IDs, request details, or network events are recorded. These counters measure use on that browser only and are not a cross-user analytics feed.
